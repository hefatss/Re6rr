# Re6rr Project Context

Native Android port of *Wangan Midnight Maximum Tune 6RR* (Enma, x86-64,
DirectX 11, Lua 5.1). The goal is the highest-fidelity reproduction of the
shipped engine, not approximation. Every fact must come from the dump or
decompilation evidence; never invent fields, semantics, mappings or instances.

## Sources of truth

- `README.md`: status table (**Done**, **Partial**, **Open**, **Out of scope**)
  and per-area summary. Read this first.
- `docs/RECON.md`, `docs/ENGINE.md`, `docs/ANDROID_HOST.md`: evidence map, C
  API, Java wrappers, and blob build/push procedures.
- `docs/P1_STATUS.md`, `docs/P3_LUA_HOST.md`, `docs/P4_PHYSICS.md`,
  `docs/P4_COURSE_RACE.md`, `docs/P5_*.md`, `docs/ASSETS_NOTES.md`: phase detail.
- `docs/recon/*.json`: derived reports from the dump, **gitignored**. Regenerate
  with `tools/recon/*.py` if missing.
- `build/tmp/*.r6*`: derived blobs, **gitignored**. Generated by
  `tools/engine/*_catalog.py`. Do not commit game data or raw blobs.

Authoritative dump: `D:\Games\W6W-05` (`wmn6r.exe`, `data/`, `data_jp/`).

## Code map

- `tools/recon/`: PE, `.pdata`, Lua, assets and Enma facts from the dump.
- `tools/x64/`: annotated disassembly, IR lift, C emit, Unicorn difftest,
  string/name-table xrefs.
- `tools/assets/`: gzip/NTWD, NDWD → OBJ, NSHR/DXBC, nut texture decode.
- `tools/lua/`: stock Lua 5.1.5 probe and script-set queries.
- `engine/include/r6/r6_*.h`: public C API. `engine/src/core`: freestanding
  core. `engine/src/assets`, `src/audio`, `src/game`, `src/render`: asset,
  audio, game and render readers. `engine/src/host`: JNI.
- `platform/android/java/com/wmmt/re6rr/`: Java wrappers for JNI.
- `CMakeLists.txt` and `tools/engine/build_host.py`: C source registration,
  host build, JNI/Java syntax checks and test registration.

## Core rules

- Freestanding core: no file I/O, inflate, WinAPI, CRT or libm. The host
  supplies bytes, memory and math callbacks (`pow`/`exp2` for envelope, engine,
  config_3d dB).
- JNI returns plain values or copied bytes. Native pointers stay in native
  code; Java sees only opaque integers where explicitly needed.
- C readers must validate magic, version, counts, offsets, capacity and bounds
  before reading. Return `R6_ERR_ARG`, `R6_ERR_FORMAT`, `R6_ERR_BUFFER` or
  `R6_ERR_NOT_FOUND` as appropriate.
- Names, RVAs, paths and bytes are copied verbatim. Do not interpret unproven
  fields and do not invent bindings.

## Derived-chunk pattern

When adding a new inventory from `docs/recon/*.json`:

1. Packer `tools/engine/<name>_catalog.py` writes `build/tmp/<name>.r6xx`.
2. Header `engine/include/r6/r6_<name>.h` plus a reader in `engine/src/core`,
   `src/assets` or `src/game`; register the source in `CMakeLists.txt` and
   `tools/engine/build_host.py`.
3. Java wrapper in `platform/android/java/com/wmmt/re6rr/` plus
   `Java_com_wmmt_re6rr_<Class>_native*` in `engine/src/host/jni.c`.
4. Test `tools/engine/test_<name>_c.py` matches every row against the JSON and
   rejects bad blob/index/row/capacity inputs.
5. Update `README.md`, `docs/ENGINE.md` and `docs/ANDROID_HOST.md` when relevant.
6. Run full validation, then commit and push `origin/master` with a complete
   message.

Static ABI facts follow the same bridge: a `void` C getter fills a caller-owned
struct, JNI flattens it into plain `long[]`/`double[]`, and a Java static method
copies it. Null output is a no-op. Do not turn a static fact into a subsystem.

## Validation

```powershell
python tools/engine/build_host.py --test --dump D:\Games\W6W-05
Get-ChildItem tools/engine/test_*.py | ForEach-Object { python $_.FullName --dump D:\Games\W6W-05 }
git diff --check
```

`git diff --check` should only show CRLF conversion warnings. Do not treat a
run as green without running every `test_*.py` script.

## Status and limits

- **Done**: P0 recon, P1 lift spike, P2 asset decode, P3 core + Lua, P4
  physics/course/race, P5 flow + catalogs, test suite.
- **Partial/Open**: per-episode story predicate instances, audio playback and
  mixer, `.EES` field semantics, GPU texture upload, real renderer driver,
  Vulkan, APK build and Android runtime.
- **Out of scope**: online, HASP/DRM and All.Net.

Known blockers: fresh Ghidra/REA import hits `provider_timeout` (use the
`docs/recon/ghidra_c/` evidence), PDB is absent, standalone Enma traces fail at
`yt::CSeq::Init()`, shader → `.nut` mapping is missing, and there is no GLES
driver or audio device for runtime validation. Do not repeat the same failed
attempt without a new reason.
